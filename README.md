# T-MINUS «Покажи один раз»

2D-игра про автоматизацию для GAMBIT Hackathon 2026, трек Gambit «AUTOMATE IT!».

Ракета стартует через три минуты, а ты — единственный инженер на степном космодроме. Сам план не выполнишь,
но можешь один раз показать работу роботу: твои действия превращаются в программу, и робот повторяет её по кругу.
Дальше ты правишь код, ставишь датчики и выравниваешь такт, чтобы линия успела к старту.

> Этот файл ведёт роль C (контент и защита). Разделы «О чём игра», «Как играть», «Команда», «Лицензии»,
> «Известные баги» и «Devlog» будут дописаны по ходу хакатона.

## Запуск

Нужен [Node.js](https://nodejs.org) 20.19 или новее.

```bash
npm install
npm run dev
```

Игра откроется на http://localhost:5173. Отладочная песочница симуляции — http://localhost:5173/debug.html.

| Команда | Что делает |
|---|---|
| `npm run dev` | Запуск для разработки с мгновенной перезагрузкой |
| `npm test` | Тесты симуляции (Vitest) |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run preview` | Локальный просмотр готовой сборки |

Во время игры интернет не нужен: всё лежит в сборке.

## Технологии

- Движок: [Phaser](https://phaser.io) 3.90.0
- Язык: TypeScript 7
- Сборка: Vite 8, тесты: Vitest 5
- AI-инструменты: Claude (Claude Code) — помощь в написании кода, тестов и документации

Полный список сторонних компонентов и лицензий — в [third_party.md](third_party.md).

## Как устроен проект

- `src/sim/` — симуляция: чистый TypeScript без движка, покрыт тестами.
- `src/types.ts` — контракт между симуляцией, экраном и данными.
- `src/scenes/`, `src/ui/`, `src/render/` — экран игры на Phaser.
- `src/data/` — уровни, баланс и тексты в JSON.
- `docs/` — брифы ролей, заметки, презентация и видео.
