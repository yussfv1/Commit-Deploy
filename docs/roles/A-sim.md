# Роль A — симуляция и сборка (Асмир)

Ты отвечаешь за «мозг» игры и за то, чтобы проект собирался и деплоился. Весь код в `src/sim/` —
чистый TypeScript **без импорта Phaser**, поэтому он тестируется Vitest-ом без браузера.
Владеешь: `src/sim/**`, `src/types.ts`, `debug.html`, `package.json`, `tsconfig.json`, `vite.config.ts`, `.github/**`.

## Что уже сделано (11.11)

- Каркас: Vite 8 + Phaser 3.90 + TypeScript 7 + Vitest 5, сборка в `dist/`, CI и автодеплой на GitHub Pages.
- Контракт `src/types.ts`.
- Симуляция целиком: машины-автоматы, робот-интерпретатор, промахи, ДАТЧИК, репетиция с записью,
  правка программ, копии роботов, покупка и продажа машин, энергия, победа/поражение/звёзды,
  бесконечный режим, телеметрия с поиском узкого места, сохранение и загрузка.
- 67 тестов (`npm test`), включая стресс: 10 минут игры на 8 роботах.
- Отладочная песочница `debug.html` — играть в симуляцию без экрана игры.
- Объяснения для защиты: `docs/notes-asmir.md`.

## Как устроен код

| Файл | Что в нём |
|---|---|
| `simulation.ts` | Фасад `Simulation implements ISimulation`: режимы, репетиция, накопитель времени, снимок, сохранение |
| `world.ts` | Мир: один тик = ходы роботов + работа машин + проверка цели; интерпретатор робота |
| `machine.ts` | Машина как конечный автомат, поведение задаётся данными (`kind`) |
| `robot.ts` | Состояние робота и его телеметрия круга |
| `program.ts` | Нормализация, проверка и «проигрывание» программы по карте (маршрут петли) |
| `telemetry.ts` | Темп линии, нужный темп, поиск узкого места |
| `level.ts` | Проверка уровня с понятными ошибками, поправки `defOverrides` |
| `grid.ts`, `rng.ts`, `ring.ts` | Карта, детерминированный ГСЧ, кольцевой буфер загрузки |
| `examples.ts` | Примеры машин и уровней для тестов и песочницы |
