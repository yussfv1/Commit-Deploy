# Роль B — экран и управление (Жалгасхан)

Ты делаешь всё, что игрок видит и трогает: сцены, отрисовку, режим обучения, панель программы, телеметрию и «сочность».
Ты **не пишешь игровую логику** — она уже готова в `src/sim` (роль A). Ты рисуешь `sim.snapshot()` и вызываешь методы `ISimulation`.
Владеешь: `index.html`, `src/main.ts`, `src/scenes/**`, `src/ui/**`, `src/render/**`.

## С чего начать

1. Поставить Node.js 20.19+, Git, Claude Code. Клонировать репозиторий, ветка `ui`. `npm install`, `npm run dev`.
2. Открыть `http://localhost:5173/debug.html` и поиграть 5 минут: это отладочная песочница симуляции
   (без Phaser, на голом canvas). Так ты поймёшь механику руками.
3. Прочитать `src/types.ts` целиком и `src/sim/debug/playground.ts` — это рабочий образец того,
   как водить симуляцию: загрузка уровня, цикл `step → snapshot → рисуем`, ввод в репетиции, правка программы.
4. Симуляция уже работает, поэтому фейковые данные не нужны: бери `Simulation` и уровни из
   `src/sim/examples.ts`, пока C не положит настоящие в `src/data/`.

```ts
import { Simulation } from '../sim';
import { EXAMPLE_DEFS, EXAMPLE_LEVELS } from '../sim/examples';

const sim = new Simulation();
sim.loadLevel(EXAMPLE_LEVELS[0], EXAMPLE_DEFS);
// в update(time, delta) сцены:
const events = sim.step((delta / 1000) * speed);   // speed = 1, 2 или 4; на паузе step не вызываем
const snap = sim.snapshot();                        // рисуем только из него
```

## Раскладка экрана 1280×720

- Сверху полоса 56 px: **T−2:41**, план (доставлено/нужно), энергия, ×1/×2/×4, пауза.
- Поле 16×9 клеток по 64 px = 1024×576, слева, от y = 56. Уровни бывают меньше — центрируй поле.
- Справа панель 256 px: выбранный робот — его программа лентой блоков и кнопки правки; или выбранная машина.
- Снизу полоса 88 px: телеметрия (полосы кругов роботов, «темп 2,1/мин · нужно 3,2/мин»), кнопки покупки, СТАРТ.

## Визуальный стиль

Плоский минимализм «как схема метро»: тёмно-синий пол с тонкой сеткой, машины — скруглённые плитки с иконкой
и полоской прогресса, роботы — кружки своего цвета (`ROBOT_COLORS[robot.colorIndex]`) с «глазом» по направлению.
**Петля каждого робота рисуется светящейся линией его цвета по клеткам `robot.path`** — это главная фишка вида.
Почти всё — `Phaser.GameObjects.Graphics`, PNG от C только для иконок предметов, ракеты и логотипа.
Палитра — в `docs/assets-list.md`.

## Задачи по порядку

1. **Сцены** — Boot (загрузка; если PNG нет — нарисовать заглушку кодом под тем же ключом из
   `docs/assets-list.md`), Menu, LevelSelect (звёзды), Game, Pause, Results, Settings (громкость), Credits.
   Переходы — плавное затемнение.
2. **Отрисовка** — `Map<id, объект>` для машин и роботов, создавать/удалять по разнице снимков.
   Позиция робота: `px + (x - px) * snap.alpha`. Лампочка машины по `state`: `working` зелёная, `ready` жёлтая,
   `idle` серая, `full` синяя; полоска `progress`. Робот по `state`: `miss` — красная вспышка,
   `sense` — мигание датчика, `carry` — предмет над роботом. Стены и доки бери из `sim.getLevel()`.
3. **Петли** — линия по `robot.path`, полупрозрачная, ярче у выбранного. Перерисовывать только когда
   программа изменилась, а не каждый кадр.
4. **Режим обучения** — клик по доку → `sim.beginTeach(dock)`. Синий фильтр и надпись
   «РЕЖИМ ОБУЧЕНИЯ — настоящий мир на паузе». Стрелки/WASD → `teachInput('up'…)`, E → `'act'`, Пробел → `'wait'`
   (удержание Пробела — автоповтор). Если ответ `ok: false` — короткая подсказка `t('fail.' + reason)` и звук ошибки.
   Счётчик «блок N из maxProgram» (`snap.operator.blocks`, `sim.getLevel().maxProgram`), лента `snap.recording`
   растёт в правой панели. Когда `snap.canFinishTeach` — кнопка «Готово» (и Enter) → `finishTeach()`;
   если игрок не на доке — подсказка «Вернись на док, чтобы замкнуть петлю». Esc — `cancelTeach()`.
   В репетиции оператор рисуется из `snap.operator` (плавно сдвигай из `px,py` в `x,y`).
5. **Панель программы** — лента блоков (↑ ↓ ← → ВЗЯТЬ ПОЛОЖИТЬ ЖДАТЬ×N ДАТЧИК), текущий блок `robot.pc`
   подсвечен. Клик — выделить. Кнопки: «Удалить блок», «Вставить ДАТЧИК» (перед выбранным ВЗЯТЬ/ПОЛОЖИТЬ,
   если `'sense'` есть в `allowedOps`), «−/+» у ЖДАТЬ, «Перезаписать» (`beginTeach(robot.dock, robot.id)`),
   «Копия со сдвигом» (`copyRobot(id, delaySteps)` — предложи половину круга), «Убрать робота».
   Перед правкой вызывай `checkProgram` — если нельзя, покажи причину; правка → `setProgram`.
   Пока правка ждёт конца круга, показывай `robot.pendingProgram` с пометкой «со следующего круга».
   Кнопка «Показать как код» — та же программа текстом:
   `повторять всегда: вправо ×3; взять; ждать датчик; …` (сильный момент для жюри — запись стала кодом).
6. **HUD и обучение уровня 1** — клавиши: Пробел — пауза (вне обучения), 1/2/3 — скорость,
   Tab — развернуть телеметрию (отменить фокус браузера), Esc — меню. Обучение по `level.tutorial`: шаги
   «нажми на док → дойди до склада → E → отнеси на стол → E → вернись на док → Готово → СТАРТ», переход по событиям.
   Прыгающая стрелка над нужной клеткой. Цель: незнакомый человек понимает, что делать, за 60 секунд.
7. **Покупки** — кнопки для `level.buildable`; призрак-превью зелёный/красный по `canBuy(type, x, y)`;
   клик → `buy`; ПКМ по купленной машине → `sell`.
8. **Телеметрия** — по полосе на робота из `robot.timeline` (цвета: идёт пустой / несёт / действует / ждёт /
   датчик / промах), подписи `cycleTime` и `usefulShare`. Строка `throughput` против `requiredRate`.
   Пульсирующая рамка вокруг `snap.bottleneck` и подсказка `t('bottleneck.' + reason)`.
9. **Сочность** — тихий бип на событие `step`, звуки на `took`/`put`/`miss`/`delivered`/`produced`, частицы на столе,
   **старт ракеты** по событию `launch`: отсчёт 3-2-1, дым, тряска камеры, ракета уходит вверх. Итог — по `won`/`lost`.
10. **Производительность** — F показывает FPS. Проверить 60 FPS в Chrome и Firefox на ×4 с 8 роботами.

## Тексты и шрифт

- Ни одной строки текста в коде: только `t('menu.play')` из `src/ui/i18n.ts`, который читает
  `src/data/strings/ru.json`. Новый ключ — дописываешь в конец `ru.json`, C потом правит формулировку.
  Если ключа нет — показывать сам ключ, а не падать.
- Шрифт — локальный файл из `public/assets/fonts/` через `@font-face` в `index.html`; дождаться
  `document.fonts.load(...)` до создания текста. Никаких Google Fonts по ссылке.
- Настройки громкости и пройденные уровни — в `localStorage` внутри `try/catch`.

## Что ты должен уметь объяснить жюри

- Как экран отделён от логики (рисуем только снимок состояния) и зачем.
- Как сделана плавность при 20 тиках в секунду (интерполяция по `alpha`) и как держится 60 FPS.
- Как устроены режим обучения и панель программы и почему игрок понимает цель за 60 секунд (цифры плейтеста от C).
